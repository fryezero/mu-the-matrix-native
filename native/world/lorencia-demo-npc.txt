# DEMO NPC TALK TABLE for Lorencia (world 0) - NOT client data and NOT a server reading.
#
# There is no server in the native session. In the real game the server
# answers the talk request with a result byte, sends the shop list and the
# vault contents, and decides every purchase. This file stands in for those
# answers (NATIVE-NPC-001). What the client does with the answer is
# reconstructed (reconstructed/npc: ReceiveTalk 0x01280659 opens the window
# of the result byte). The texts are the client's own tables when MU_LANG_DIR
# is set: Npcname for titles, Dialog(kor) indices for the demo dialogue.
#
#   talk <server-class> <result-byte> [dialog <index> ...] [options <index> ...]
#   shop <server-class> <item-code>[+level] ...    (item code = group * 512 + index)
#   storage <item-code>[+level] ...
#   actor ...                                      (extra placement line, see lorencia-demo-placement.txt)
#
# NPCs without a talk row answer 0xff (no window).
